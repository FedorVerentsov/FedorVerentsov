## How I approach testing

I start with requirements, business risks and the user journey. I check successful flows and failure paths, investigate issues through API responses, logs and database queries, and document defects with reproducible steps and clear expected results.

For financial and blockchain workflows, I pay particular attention to:

- Balance consistency, fees, precision and rounding.
- Transaction states, failed operations and recovery.
- Wallet connections and differences between networks.
- UI and API consistency.
- Regression risks around critical user journeys.
